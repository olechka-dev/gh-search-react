# React GitHub Search

A demo React project for searching GitHub repositories using the GitHub API.

The app uses React and TypeScript, Vite for development and builds, React Router, TanStack Query, Material UI, and Tailwind CSS.

## Getting started

Install Node.js (20.19.x or 22.12 and later) and npm, then install the dependencies and start the development server:

```sh
npm install
npm run dev
```

Open the local URL printed in the terminal.

## Build and preview

```sh
npm run build
npm run preview
```

The build is written to `dist`; the preview command serves it locally.
